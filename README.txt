POLICIAL RESGATA O GATO + TIKTOK LIVE

1) Suba esta pasta para um repositório no GitHub (pode ser pelo site github.com no navegador).
2) Em render.com: New > Web Service > escolha o repositório.
   - Build Command: npm install
   - Start Command: npm start
   - Environment: TIKTOK_USER = seu @ (sem o @)
3) Quando ficar "Live", abra o endereço que o Render mostrar (https://....onrender.com).
   O jogo abre e passa a reagir à sua live: presentes dão dano e comentário com "atacar" ataca.
4) Teste: entre na sua live. Em https://SEU-ENDERECO/status aparece conectado: true.

Presentes: Rose/Rosa, Donut/Rosquinha e Finger Heart/Dedinho usam os danos dos botões.
Outros presentes causam dano pelo valor em moedas.

Aviso: a biblioteca é não oficial e pode parar de funcionar se o TikTok mudar algo.
O plano grátis do Render pode "dormir" sem uso; abra o endereço antes de começar a live.
